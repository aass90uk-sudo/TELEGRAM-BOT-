## ✨ غِذَاءُ أَرْوَاحِ المُوَحِّدِينَ وَشِفَاءُ الصُّدُورِ

> **قال الله تعالى:** *{الَّذِينَ آمَنُوا وَتَطْمَئِنُّ قُلُوبُهُم بِذِكْرِ اللَّهِ ۗ أَلَا بِذِكْرِ اللَّهِ تَطْمَئِنُّ الْقُلُوبُ}* [الرعد: 28]

مشروع برمجى إسلامي متكامل لبناء بوت تلغرام (Telegram Bot) متطور مخصص للاستماع وتحميل سور القرآن الكريم كاملة بصيغة صوتية عالية الجودة. يعتمد البوت على الاتصال المباشر بالمكتبة الصوتية الشاملة لشبكة **MP3Quran** ليوفر للمشترك مئات القراء الأفاضل بتنظيم ذكي وسلس.

---

## 🚀 المميزات التقنية والفنية للمشروع

- **🤖 تجربة مستخدم ديناميكية (Pagination):** تقسيم القراء إلى صفحات منظمة (أزرار إنلاين) لمنع ازدحام واجهة المستخدم والتصفح السلس لأكثر من 100 قارئ.
- **📢 زر المشاركة الملهمة:** زر تفاعلي مدمج يتيح للمشتركين مشاركة البوت مع أصدقائهم بـ (رسالة دعوية مؤثرة) ليكون صدقة جارية متبادلة.
- **⚡ جلب لحظي وديناميكي (Live API):** لا يتم تخزين الملفات الصوتية محلياً؛ بل يجلب البوت روابط السور مباشرة من الخوادم الرسمية لضمان السرعة وتوفير المساحة.
- **📱 أزرار رد مخصصة (Reply Keyboards):** بمجرد اختيار القارئ، تظهر قائمة السور المتاحة له أسفل حقل الكتابة بشكل منسق مع خيار العودة للقائمة الرئيسية.
- **☁️ جاهز للنشر السحابي:** الكود مهيأ بالكامل للرفع المباشر على منصات الاستضافة مثل Railway أو Heroku عبر استخدام المتغيرات البيئية (Environment Variables) لحماية توكن البوت.

## 🛠️ هيكلية وتكوين الملفات (Project Structure)

يتكون المشروع من الملفات الأساسية التالية:
📂 `bot.py` -> الملف البرمجي الرئيسي الذي يحتوي على منطق عمل البوت والاتصال بالـ API.
📄 `requirements.txt` -> مكتبات بايثون المطلوبة للتشغيل وضمان التوافقية.
⚙️ `Procfile` -> ملف إدارة العمليات السحابية والمسؤول عن توجيه منصة ريلواي لتشغيل البوت في الخلفية.

## 💻 متطلبات التثبيت والتشغيل المحلي (Local Setup)

إذا كنت ترغب في تشغيل المشروع وتجربته على جهازك الشخصي أولاً، اتبع الخطوات التالية:

### 1. استنساخ المستودع (Clone)
```bash
git clone https://github.com
cd quran-telegram-bot
```

### 2. تثبيت المكتبات (Dependencies)
```bash
pip install -r requirements.txt
```

### 3. إعداد متغير التوكن البيئي (Environment Variable)
قم بضبط توكن البوت الخاص بك (الذي حصلت عليه من BotFather):
- **على أنظمة ويندوز (CMD):**
  ```cmd
  set TELEGRAM_TOKEN=your_bot_token_here
  ```
- **على أنظمة لينكس وماك:**
  ```bash
  export TELEGRAM_TOKEN="your_bot_token_here"
  ```

### 4. تشغيل البوت
```bash
python bot.py
```

## ☁️ النشر على منصة ريلواي (Railway Deployment)

1. ارفع الكود إلى حسابك الشخصي على **GitHub**.
2. اربط حساب GitHub بمنصة **[Railway](https://railway.com)**.
3. قم بإنشاء مشروع جديد واختر المستودع الخاص بالبوت.
4. انتقل إلى تبويب **Variables** في ريلواي وأضف المتغير التالي:
   - **الاسم (Key):** `TELEGRAM_TOKEN`
   - **القيمة (Value):** `توكن_البوت_الخاص_بك_هنا`
5. اترك المنصة تبني المشروع وتطلقه تلقائياً، وسيعمل البوت على مدار 24 ساعة دون انقطاع.
